# RastAI

A Chrome extension that fixes garbled Persian/English bidirectional (bidi)
text rendering inside AI chat web apps (ChatGPT, Claude.ai, Gemini,
Perplexity, and similar). When a Persian sentence contains an embedded
English word or number, browsers sometimes misorder it along with
neighboring punctuation; this extension corrects paragraph-level text
direction and isolates embedded Latin tokens so everything renders in the
right order. Manifest V3, vanilla JS, no build step, no external
dependencies.

## توضیحات فارسی

این افزونه مشکل به‌هم‌ریختگی ترتیب نمایش کلمات/اعداد انگلیسی داخل متن فارسی را
در چت‌بات‌های هوش مصنوعی وب (ChatGPT، Claude.ai، Gemini، Perplexity و مشابه)
اصلاح می‌کند.

⚠️ این افزونه **فقط روی دامنه‌های ذکرشده در `manifest.json`** (لیست
`content_scripts.matches`) اجرا می‌شود، نه روی کل وب — چون اجرای آن روی
سایت‌هایی مثل تلگرام وب یا هر سایتی که از رندر پویا/لیست مجازی‌سازی‌شده
استفاده می‌کند، می‌تواند در منطق داخلی آن سایت اختلال ایجاد کند (مثلاً برش
اشتباه متن‌های طولانی).

اگر از یک سایت هوش مصنوعی دیگر استفاده می‌کنید که در لیست نیست، کافی است در
`manifest.json` داخل آرایه‌ی `matches` یک خط مثل زیر اضافه کنید (با آدرس همان
سایت) و افزونه را از `chrome://extensions` ریلود کنید:

```json
"https://example-ai-site.com/*"
```

### چطور کار می‌کند؟

مرورگرها از الگوریتم استاندارد یونیکد برای تعیین جهت متن (Bidi) استفاده
می‌کنند. وقتی یک کلمه یا عدد انگلیسی وسط یک جمله‌ی فارسی می‌آید، این الگوریتم
گاهی جهت آن کلمه را همراه با علائم نگارشی مجاورش (پرانتز، دونقطه و…) اشتباه
تشخیص می‌دهد و ترتیب نمایش به‌هم می‌ریزد. مشکل مهم‌تر این است که وقتی یک
پاراگراف فارسی با یک کلمه‌ی انگلیسی شروع می‌شود، مرورگر گاهی کل پاراگراف را
اشتباهاً چپ‌به‌راست در نظر می‌گیرد.

این افزونه دو کار می‌کند:

1. روی بلوک‌های متنی (پاراگراف، آیتم لیست و…) که اکثریت محتوایشان فارسی است،
   جهت را صراحتاً `dir="rtl"` می‌گذارد — با شمارش واقعی حروف، نه فقط حرف اول.
2. هر بخش انگلیسی/عددیِ داخل جمله‌ی فارسی را داخل تگ استاندارد HTML به نام
   `<bdi dir="ltr">` قرار می‌دهد تا جهت آن مستقل از متن اطرافش تعیین شود.

این کارها فقط روی متن‌هایی انجام می‌شود که واقعاً ترکیبی از فارسی و انگلیسی
هستند؛ صفحات یا بخش‌های خالص انگلیسی دست‌نخورده باقی می‌مانند. همچنین داخل
`textarea`، `input` و بخش‌های قابل‌ویرایش (مثل کادر تایپ در چت‌بات‌ها) هیچ
تغییری اعمال نمی‌شود تا در تایپ کردن شما اختلالی ایجاد نشود.

### نصب (به‌صورت Unpacked / بدون Chrome Web Store)

1. مخزن را دانلود/کلون کنید.
2. در کروم به آدرس زیر بروید:
   `chrome://extensions`
3. گزینه‌ی «حالت توسعه‌دهنده» (Developer mode) را در گوشه‌ی بالا سمت راست
   صفحه فعال کنید.
4. روی «Load unpacked» کلیک کنید و پوشه‌ی پروژه را انتخاب کنید.
5. افزونه فقط روی سایت‌های چت‌بات هوش مصنوعیِ لیست‌شده در manifest فعال
   می‌شود. برای صفحاتی که از قبل باز بودند، یک‌بار رفرش (F5) بزنید.

با کلیک روی آیکون افزونه در نوار ابزار کروم می‌توانید آن را موقتاً خاموش/روشن
کنید (فقط برای سایت‌های همان لیست، نه کل وب).

**نکته‌ی مهم بعد از هر تغییر در فایل‌های افزونه:** صرف رفرش‌کردن تب سایت کافی
نیست؛ باید از `chrome://extensions` روی آیکون ریفرش دایره‌ای خودِ افزونه هم
بزنید تا کد جدید بارگذاری شود.

### محدودیت‌ها

- این یک راه‌حل عمومی و مبتنی بر الگو (heuristic) است، نه یک پردازشگر زبان
  کامل؛ در موارد خیلی خاص و پیچیده (مثل ترکیب چندلایه‌ی فارسی/انگلیسی/کد) ممکن
  است نیاز به تنظیم دستی regex داخل `content.js` باشد.
- داخل بلوک‌های کد (`<code>`, `<pre>`) و کادرهای قابل‌ویرایش تغییری اعمال
  نمی‌شود؛ این کار عمدی است تا فرمت کد و تایپ شما خراب نشود.
- اگر سایتی محتوای خود را داخل Shadow DOM بسته (closed) رندر کند، این افزونه
  (مثل هر افزونه‌ی دیگری) به آن دسترسی ندارد.
